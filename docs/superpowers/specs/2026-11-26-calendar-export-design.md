# 마감일 캘린더에 넣기 (.ics + Google 캘린더 링크) — 짧은 설계

작성일: 2026-11-26 · 상태: 사용자 승인 (2026-11-26)

## 왜
학생이 실제로 놓치는 것은 공모전·채용 마감일이에요. 사이트에서 본 마감일을 자기 캘린더에 한 번에 넣어서 캘린더 알림이 챙겨 주게 해요. (근거: 2026-11-25 검수 4_ops_improve C-1, 사용자가 기능 아이디어 중 첫 번째로 고름)

## 목표 / 안 할 것 / 실패로 보는 것
- 목표: 공모전·채용 상세에서 마감일을 Google 캘린더나 다른 캘린더(아이폰·삼성·PC)에 넣을 수 있어요.
- 안 할 것: 구독형 캘린더 주소(webcal, 서버 필요), 여러 건 한꺼번에 내보내기, 뉴스·알바·SW 프로그램, 결과 발표일 일정.
- 실패로 보는 것: 버튼을 눌렀는데 아무 일도 안 일어나는 기기가 흔한 경우, 날짜가 하루 밀려 들어가는 경우, 사이트에 이모지가 생기는 경우.

## 방식 (사용자가 고름: 2번)
1. .ics 파일 버튼만: 버튼이 하나라 단순하지만, Google 캘린더 앱 사용자(아이폰은 기본 캘린더로 감, 안드로이드는 앱 버전에 따라 다름)는 잘 안 될 수 있어요.
2. **.ics 버튼 + "Google 캘린더" 링크 (선택)**: 로그인이 Google 계정뿐이라 학생 대부분이 Google 계정이 있어요. 링크는 파일 없이 Google 캘린더 일정 입력 화면을 바로 열어요. 버튼이 하나 느는 대신 누구나 한 번에 넣어요.

## 설계
- 자리: 공모전·채용 상세(`static/v2_pages.js` `detailHtml`) 하나. PC 오른쪽 상세와 모바일 아래 시트가 같은 함수를 쓰니 두 화면 모두에 생겨요. 기존 버튼 줄 아래에 한 줄을 더 둬요.

  ```
  [원문 보기]  [저장]  [도전 목록에 추가]
  마감일 캘린더에 넣기   [Google 캘린더]  [다른 캘린더 (.ics)]
  ```
- 보이는 조건: 마감일이 날짜(YYYY-MM-DD)이고 오늘 이후일 때만. "상시 모집"·마감 지난 공고에는 줄 자체가 없어요.
- 일정 내용 (두 방식 같게):
  - 하루 종일 일정, 날짜 = 마감일 (시간 정보가 없어서 하루 종일로 둬요. 시간대 때문에 날짜가 밀리지 않음)
  - 제목: `[마감] 공고 제목` (채용은 직무명 + 기관)
  - 설명: 주최/기관, 원문 링크(`https?://`일 때만), "토목 뉴스 브리핑에서 추가"
- .ics: 브라우저에서 파일을 만들어 내려받아요(서버 없음). 같은 공고를 다시 넣어도 겹치지 않게 공고마다 고정 UID(`<kind>-<id>@civil-news-hub.vercel.app`). 알림은 마감 3일 전·1일 전 오전 9시(사이트의 "곧 마감" 기준이 D-3이라서). 줄 끝 CRLF, 75바이트 접기, `,;\` 이스케이프는 RFC 5545대로.
- Google 링크: `https://calendar.google.com/calendar/render?action=TEMPLATE&text=…&dates=YYYYMMDD/다음날&details=…`, 새 탭. Google은 링크로 알림을 정할 수 없어 사용자의 기본 알림을 따라요.
- 일정 글자를 만드는 순수 함수는 `static/v2_core.js`에 두고 `tests/v2_core.test.js`로 검사해요(날짜 경계, 이스케이프, 접기, 링크 인코딩). 내려받기 클릭 처리만 `v2_pages.js`.
- 사이트 규칙: 이모지 없음(글자 + 기존 SVG 아이콘), PC·모바일 각자 스타일 범위(`#v2m .dt-acts .btn{flex:1}`처럼).
- 개인정보: 아무것도 저장·전송하지 않아요. Google 링크를 누르면 공고 제목·마감일이 Google로 가는데, 사용자가 직접 누른 이동이라 처리방침 변경은 필요 없어요. CSP는 내려받기·새 탭 이동을 막지 않아요.

## 만드는 사람이 정할 것
- 내려받기 방법(blob 링크 + download 속성 등). 아이폰 Safari에서 파일이 "캘린더에 추가" 화면으로 열리는지 실제 기기로 확인 필요(사용자 휴대폰으로 확인).
- 파일 이름, 버튼의 SVG 아이콘, 줄 간격.

## 확인 방법
- `node --test tests/*.test.js`, `python -m pytest -q tests`(이모지 검사 포함)
- 사용자 휴대폰(아이폰 또는 안드로이드)에서 두 버튼 모두 눌러 캘린더에 마감일 날짜로 들어가는지
